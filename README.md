# ⚠️ G00DS0UL Rogue Game (V1 - Deprecated)

**Status: Archived / Migrated**

This repository contains the original terminal-based prototype for my custom C# Roguelike game engine. It was built as a proof-of-concept to handle basic grid movement, map generation, and simple entity scheduling.

### 🚀 Migration Notice
During development, I realized the architecture required a more robust rendering loop, decoupled UI systems, and persistent memory states that standard console output couldn't handle efficiently. 

Development has officially moved to a new repository built on the **MonoGame Framework**. The core engine has been completely re-architected with deep Object-Oriented principles.

**👉 You can view the active, upgraded engine here:** [G00DS0ULMonoGame repository](https://github.com/G00dS0ul/RogueGame-MonoGame)

### Tech Stack (V1)
* C# / .NET
* RogueSharp (Terminal Output)
